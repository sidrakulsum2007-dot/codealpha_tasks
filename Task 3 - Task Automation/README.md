# CodeAlpha Task Automation

## 📌 Project Description

This project is a simple task automation script developed using Python as part of the CodeAlpha Python Programming Internship.

The program automatically finds JPG and JPEG image files in a source folder and moves them to a destination folder.

## 🎯 Objective

The objective of this project is to automate a simple repetitive file-management task using Python.

## ✨ Features

- Automatically checks files in the source folder
- Identifies JPG and JPEG image files
- Creates the destination folder if it does not exist
- Automatically moves image files to the destination folder
- Displays the names of files that have been moved
- Provides a completion message

## 🛠️ Technologies Used

- Python
- os module
- shutil module

## 🧠 Python Concepts Used

- File handling
- `os` module
- `shutil` module
- `if` statements
- `for` loop
- File and folder paths
- String methods

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Place JPG or JPEG files inside `source_folder`.
4. Open the terminal.
5. Run:

```bash
python automation.py
