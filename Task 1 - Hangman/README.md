# CodeAlpha Hangman Game

## 📌 Project Description

This project is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time. The player is allowed a maximum of 6 incorrect guesses.

## 🎯 Objective

The objective of this project is to create a simple console-based game while practicing basic Python programming concepts.

## ✨ Features

- Contains 5 predefined words
- Randomly selects a word
- Allows the player to guess one letter at a time
- Displays correctly guessed letters
- Allows a maximum of 6 incorrect guesses
- Checks for repeated guesses
- Validates user input
- Displays win or game-over messages

## 🛠️ Technologies Used

- Python
- Random module

## 🧠 Python Concepts Used

- Lists
- Strings
- Variables
- `if-else` statements
- `while` loop
- `for` loop
- Functions and built-in methods
- User input
- Random selection
